# flori-travel.de

Statische Seite für GitHub Pages: Einladungslink (`/join?c=CODE`), Apple-Prüfdatei für Universal Links
(`.well-known/apple-app-site-association`) und eine kleine Startseite. Der flori-Worker bleibt unverändert.

Deploy: Inhalt dieses Ordners in das GitHub-Repository `flori-site` (Branch `main`, Root) legen,
unter Settings → Pages „Deploy from a branch“ wählen, Custom domain `flori-travel.de`, „Enforce HTTPS“.
